# StatusPulse

A containerized FastAPI service with PostgreSQL and Redis integration.

## Features

- FastAPI backend
- PostgreSQL database
- Redis cache
- Dockerized setup
- Docker Compose orchestration
- GitHub Actions CI/CD
- Healthcheck endpoint
- Integration testing
- GHCR image publishing

---

## Tech Stack

- Python 3.11
- FastAPI
- PostgreSQL
- Redis
- Docker
- GitHub Actions
